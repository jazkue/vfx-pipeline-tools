# Unreal Publish Template

A Nuke tool for preparing Unreal render outputs from production context.

## Workflow

1. Create a publish template in Nuke.
2. Generate the Unreal output paths.
3. Use the paths in Unreal's render settings.
4. Render the multilayer EXR.
5. Return to Nuke and create the corresponding Read node.

## Technical focus

- Nuke / Unreal integration
- Context-based path generation
- Multilayer EXR workflow
- Automated Nuke setup

The production source code is not included.
